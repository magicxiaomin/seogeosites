# SEO/GEO Factory MVP Workflow

Default strategy: build one production pilot site plus one staging/sandbox preview path. Do not mass-create websites or publish unreviewed AI content.

Pipeline:

```text
opportunity pool
→ SEO/GEO/Risk strategy classification
→ evidence/source/trust plan
→ site placement decision
→ content brief
→ staging draft
→ QA report
→ build preview
→ human approval gate
```

Placement rule: prefer updating or expanding an existing site. Create a new site only when audience, entity posture, risk class, language/region, or monetization model clearly requires a separate brand.
